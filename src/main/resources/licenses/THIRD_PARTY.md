# VulkanMod (unofficial 26.2 port) — licences

This is an unofficial port of **VulkanMod** 0.6.8 by Collateral (https://github.com/xCollateral/VulkanMod) to Minecraft 26.2.
It contains the code of VulkanMod adapted to the new game version, plus fixes for bugs found while porting; no
additional features or optimizations. VulkanMod and therefore this port are licensed under the
**GNU Lesser General Public License v3.0** (see LICENSE-VulkanMod.txt). Source code of this port: https://github.com/DriedApricots/VulkanMod-Port
